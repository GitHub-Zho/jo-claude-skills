# 视觉系统

## 1. 先测量参考稿

若用户提供旧 PDF 或模板，先获取：

- 页面尺寸和页边距；
- 正文版心左右边界；
- 姓名、一级标题、条目标题、正文、辅助信息的字号；
- 正文、标题、链接的实际颜色；
- Regular/Bold 字体名称与嵌入情况；
- 标题前后距、正文行距、段落密度；
- 右侧日期的固定横坐标；
- 每页首尾位置和主要空白区。

用测量值建立视觉档案，不凭截图印象猜测。若原字体本机缺失，选用具有真实字重且视觉接近的中文字体，并在交付说明中记录替代。

## 2. 中文 A4 默认基线

在无参考稿时使用以下起点，并根据内容与字体实测调整：

| 元素 | 建议值 |
|---|---|
| 页面 | A4，单栏 |
| 页边距 | 16–22 mm |
| 姓名 | 14–18 pt，Bold |
| 一级标题 | 10.5–12 pt，Bold |
| 公司/项目标题 | 9–10.5 pt，Semibold/Bold |
| 正文 | 9–10 pt，Regular |
| 行距 | 正文字号的 1.35–1.65 倍 |
| 颜色 | 正文深灰；标题近黑；链接最多一种蓝色 |

正文低于 9 pt 前，必须先检查重复内容、段距、版心和分页；不可通过持续缩字解决溢出。

## 3. 层级与加粗

只对扫描锚点使用真实粗体：一级标题、公司/项目名、职位、关键量化结果和少量关键技术判断。技术栈可用常规字重或轻微辅助色，不要让整页都在加粗。

同一层级使用同一字号、字重、颜色和段距。模块前距必须大于模块内部条目间距。旧稿若以连续段落而非 bullet 建立层级，保持该视觉语言，不强行改成项目符号。

## 4. 换行与中西文空格

- 让正文按版心自然换行；只有在明确语义边界处使用主动换行。
- 避免技术名、数字与单位、日期、URL 被拆开。
- 不用连续空格、空段落或软回车塑形。
- 在 OOXML 中关闭 `w:autoSpaceDE` 和 `w:autoSpaceDN`，避免 Word 自动在中文与拉丁字母/数字之间制造异常空格。
- 需要视觉间隔时，在源文本中显式加入一个半角空格并保持全篇一致。

## 5. 日期与版心

计算正文宽度：页面宽度减去左右页边距。将右对齐制表位设置在该宽度处，而不是应用提供的“页面最大位置”。长标题允许在左侧自然换行，日期固定在右上；如果标题与日期发生碰撞，把日期置于独立右对齐行，不缩小标题文字。

## 6. 页面安全区

默认把页面上下安全区写入节属性的真实 `top` / `bottom` page margins。真实页边距随内容重排和新增页面自动生效，是可编辑 DOCX 的唯一主方案。

不要用连续普通空行、空格、软回车或页尾空段落模拟安全区；它们的高度会随字体、默认段距、行距和转换器变化。

若已通过实际导出确认某个转换器忽略第二页上边距：

1. 保留正式 DOCX 的真实页边距；
2. 另建转换器专用导出副本；
3. 只在受影响页面加入一个精确行高、前后距归零的兼容留白段落；
4. 根据 PDF 实测缺口计算高度，不凭感觉添加空行；
5. 转换后逐页复验，兼容段落不得成为正式内容结构。

底部安全区始终由真实下边距控制，不在页尾堆叠空段落。

## 7. 分页

把学校、公司或项目作为不可随意拆散的信息块：标题后至少跟随一段正文；避免模块标题或项目名独占页尾。优先使用 keep-with-next、keep-lines 和块级分页控制；仅在自然边界使用硬分页。

不要为了平衡页面而删除关键内容。若第二页过空，先移动完整项目块或调整模块前后距；若两页仍拥挤，允许三页。

## 8. ATS 与视觉兼容

使用单栏和真实文本。不要依赖页眉、页脚、文本框、图标或图片承载姓名、联系方式、学校、公司、日期和技术关键词。超链接同时保留可读标签或地址。
