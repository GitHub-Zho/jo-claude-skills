## 排版行为

| 项目 | 规则 |
|---|---|
| 中西文自动空格 | 关闭 `autoSpaceDE` / `autoSpaceDN` |
| 日期对齐 | 固定在正文版心右边界 |
| 标题孤行 | 禁止 |
| 信息块跨页 | 优先整体移动；自然边界才拆分 |
| 正文限制 | 不设 1–2 行硬上限 |
| 页数 | 两页优先，必要时三页 |
